# Agent Pack Import

PDF Ebook Studio can import an Agent Pack ZIP generated by a ChatGPT/GPT workflow.

## ZIP structure

```text
pdf-ebook-studio-agent-pack.zip
├─ manifest.json
├─ project/
│  ├─ project.md
│  ├─ project-with-images.json
│  └─ project.json
├─ images/
│  ├─ page-01-cover.jpg
│  └─ page-02-example.jpg
├─ prompts/
│  ├─ image-production-sheet.md
│  ├─ image-prompts.json
│  └─ image-prompts.csv
├─ etsy/
│  ├─ listing-title.txt
│  ├─ listing-description.txt
│  ├─ tags.txt
│  ├─ whats-included.txt
│  └─ customer-readme.txt
└─ qc/
   ├─ qc-checklist.md
   └─ missing-assets-report.md
```

## Manifest

```json
{
  "format": "pdf-ebook-studio-agent-pack",
  "version": 1,
  "app": "pdf-ebook-studio",
  "primaryImport": "project/project-with-images.json",
  "fallbackMarkdown": "project/project.md",
  "imagesFolder": "images/",
  "pageCount": 20,
  "productType": "interior-magazine",
  "languageVersions": ["nl"],
  "documentFormat": "A4-portrait",
  "outputProfile": "etsy-digital-product",
  "qcStatus": "pass"
}
```

## Import behavior

1. The dashboard button `Import Agent ZIP...` accepts a `.zip` file.
2. If `project/project-with-images.json` or the manifest `primaryImport` exists, the app imports it first.
3. If the JSON contains embedded images, those images are saved with the project.
4. If the JSON has no embedded images, the app loads supported files from `images/`.
5. If no project JSON exists, the app imports `project/project.md` and then loads `images/`.

Supported image extensions are `.jpg`, `.jpeg`, `.png`, and `.webp`. Filenames must match page image fields exactly after folder prefixes are stripped.
