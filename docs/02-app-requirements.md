# PDF Ebook Studio — Requirements

## Purpose
A local-first web app that converts structured content and images into premium, sellable PDF ebooks and digital magazines.

## Supported product types
- Recipe ebooks
- Interior inspiration magazines
- Exterior inspiration magazines
- General ebooks / guides

## First version
Must support:
- A4 portrait
- Markdown import
- manual editor
- image upload
- image matching by filename
- palette presets and custom palettes
- template registry
- live preview
- PDF export
- page previews
- contact sheet
- customer ZIP
- seller ZIP / Etsy pack
- project JSON export/import
- Dutch and English versions

## No AI API
No OpenAI/Anthropic/API dependency in the app. AI-generated content/images are prepared outside the app.

## Output
- Final PDF
- Preview images
- Contact sheet
- Customer ZIP
- Seller ZIP
- Etsy Listing Pack
- QC reports
