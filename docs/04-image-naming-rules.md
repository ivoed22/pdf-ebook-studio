# Image Naming Rules

Use predictable filenames so the app can match images automatically.

## Format
`page-XX-short-slug.jpg`

## Examples
- page-01-cover.jpg
- page-07-soft-beige-retreat.jpg
- page-08-warm-walnut-luxury.jpg
- page-12-creamy-lemon-pasta.jpg

## Rules
- lowercase only
- hyphens instead of spaces
- page number with two digits
- no special characters
- supported: .jpg, .jpeg, .png, .webp
- filenames in Markdown must match uploaded files exactly
